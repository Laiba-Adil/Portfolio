

# 🎨 Laiba's Graphics – Portfolio Website

This is a simple, responsive **portfolio website** designed for a graphic designer, Laiba Adil. The website showcases her skills, services, and contact information in a clean, modern layout.

## 💻 Features

- **Responsive Design:** Optimized for desktop and mobile viewing.
- **Navigation Bar:** Easy-to-use links for Home, About, Skills, Team, and Contact sections.
- **Home Section:** Introduction with a profile image and downloadable CV.
- **Services Section:** Highlights graphic design services like flyers, vector tracing, and social media posters.
- **Skills Section:** Displays proficiency levels in tools like Adobe Illustrator, Photoshop, Canva, and After Effects using progress bars.
- **Contact Form:** Basic form to collect name, phone number, and message.
- **Footer:** Contact details including phone, email, and location.

## 🛠️ Technologies Used

- HTML5
- CSS3
